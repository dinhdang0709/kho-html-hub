🌐 TRIỂN KHAI CÔNG KHAI TRÊN GITHUB PAGES

Trình Tạo Lệnh & Kiểm Tra Đường Dẫn GitHub Pages

Bộ mã nguồn của website này đã được chuẩn hóa cấu trúc thư mục gốc (index.html, style.css, script.js, assets/, README.md) để triển khai trực tiếp lên GitHub Pages ở chế độ Public.

🔗 Link Repository Public: https://github.com/vuongdinhdang/greencode-html-hub
🌍 Link Website GitHub Pages: https://vuongdinhdang.github.io/greencode-html-hub/

Quy trình 6 bước bật GitHub Pages chuẩn:

  1. Tạo repository mới ở chế độ Public tại github.com/new.
  2. Tải lên các file trong gói mã nguồn (đảm bảo index.html nằm ngay ở thư mục gốc /(root)).
  3. Mở mục Settings → Pages trên thanh công cụ của repository.
  4. Tại mục Build and deployment, chọn Deploy from a branch.
  5. Chọn nhánh main và thư mục /(root) rồi nhấn Save.
  6. Chờ 30–60 giây để GitHub Actions hoàn tất xuất bản link công khai.
